## The essentials

Every developer has their toolkit. Here's what I've been reaching for lately.

### Editor

**VS Code** — still the king. With Copilot baked in, it's hard to imagine going back. I keep my extensions minimal: Astro, Prettier, and a good theme.

### Terminal

**Windows Terminal** with **PowerShell** — clean, fast, and customizable. I use Volta for Node version management which keeps things simple.

### Version control

**Git** with GitHub — nothing fancy. Feature branches, small commits, descriptive messages. The basics work.

## The philosophy

I try to keep my toolchain lean. Every tool should solve a real problem. If I can't explain why I need it, I probably don't.

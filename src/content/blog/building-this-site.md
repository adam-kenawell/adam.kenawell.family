## The Stack

This site is built with [Astro](https://astro.build), a modern static site builder that ships zero JavaScript by default. It's hosted on GitHub Pages, which makes deployment as simple as pushing to a branch.

## Why Astro?

I wanted something lightweight. No heavy frameworks, no client-side routing — just fast, static HTML. Astro gives me component-based authoring (like React or Svelte) without the runtime cost.

## The design

I went with a black and yellow color scheme with a pixelated retro font called **Fusion Pixel**. The goal was something that feels playful but still clean and professional.

## What's next

I'm planning to add more interactivity over time — maybe some animations, a project showcase with live demos, and a proper blog with tags and search. But for now, simple is good.
